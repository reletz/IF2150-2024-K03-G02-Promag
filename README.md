## Getting Started

### Prerequisites

- npm
  ```sh
  npm install npm@latest -g
  ```

### Installation

1. Clone the repo
   ```sh
   git clone https://github.com/reletz/IF2150-2024-K03-G02-Promag.git
   ```
2. Install NPM packages
   ```sh
   npm install
   ```
3. Run program<br> With hot reload:
    ```sh
    npm run dev
    ```
    Without hot reload:
    ```sh
    npm start
    ```
